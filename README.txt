주변 의료기기 현황 웹 서비스

1. 실행 방법
- nearby-medical-devices 폴더의 파일 4개(index.html, style.css, app.js, data.json)를 같은 폴더에 둡니다.
- 아래 방법 중 하나로 로컬 웹 서버를 실행합니다.
  * Python 설치 시: 해당 폴더에서 터미널을 열고 `python -m http.server 8000` 실행
  * 브라우저에서 `http://localhost:8000` 접속
- index.html 파일을 더블클릭(file://)하면 브라우저 보안 정책으로 data.json을 읽지 못할 수 있으므로 로컬 서버 실행을 권장합니다.
- 인터넷 연결이 있으면 글꼴과 외부 지도 링크를 사용할 수 있습니다. 검색 기능 자체는 로컬 data.json으로 작동합니다.

2. 파일 구성
- index.html : 화면 구조 및 입력/검색 UI
- style.css : PC·모바일 반응형 디자인
- app.js : 지역 선택, 필수값 검사, 검색, 상세정보 표시
- data.json : 첨부 CSV에서 추출·정리한 의료기관 및 장비 데이터

3. 데이터 처리 기준
- 원본 CSV 인코딩: CP949
- 전체 원본 행: 768
- 검색 데이터 행: 270 (영업상태명='운영중' AND 사용구분명='사용중')
- 검색 데이터 의료기관(기관명+도로명주소 기준): 270
- 의료기기 종류: CT, MRI
- 전화번호는 원본 CSV에 없어 제공하지 않습니다.
- 원본 자료의 기준일이 명시되지 않아 실시간 현황을 보장하지 않습니다.
- 유방촬영장치, PET-CT 등 CSV에 없는 장비는 검색 대상에 포함하지 않습니다.

4. 주의
검색 결과는 제공된 CSV의 등록 내용을 그대로 활용한 정보 조회 결과입니다.
실제 검사 가능 여부, 예약 가능 여부, 현재 장비 가동 여부를 보증하지 않습니다.
방문 전 해당 의료기관에 직접 확인하세요.
